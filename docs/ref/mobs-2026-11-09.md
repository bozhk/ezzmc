# Мобы: что сделано и как добавлять (2026-11-09)

Всё собрано в release, **вживую не проверено** (тестирует владелец). Эталон: `reference/26.3/client/net/minecraft/client/model/**` и `renderer/entity/*Renderer.java`.

## Как устроено
- `crates/client/src/mobs.rs`: `spec(name)` → `Spec{tex,kind,scale,shadow,mscale,lit}`; `Kind` enum; `build(kind)` → `Rig`; ветка анимации в `Mobs::bake` (`Rig::Plain` → `match sp.kind`). `mscale` = `MeshTransformer.scaling` модели (ghast 4.5, cat 0.8, polar_bear 1.2, donkey 0.87, mule 0.92).
- `crates/render/src/animals.rs`: `*_mesh()` + `*_anim()`; гуманоиды (`Rig::Human`, нужны `HumanoidParts`) — `humanoid_parts(&m)`, `humanoid.rs`.
- API модели: `Model::add(name, parent, Pose, &[BoxDef::new(uv,origin,dim).grow(g).mirror()])`, `Part.visible`, `reset_pose()`. Имена частей `&'static str`.
- Рецепт нового моба: 1) прочитать `XModel.createBodyLayer` и `setupAnim`; 2) перенести боксы 1:1 (CubeDeformation → `.grow`); 3) строка в `spec()` (текстура `entity/<tex>.png` берётся из jar `dist/ezzmc-windows/minecraft/versions/26.3/26.3.jar`); 4) `Kind` + `build` + ветка в `Rig::Plain`; 5) `cargo build --release -p ezzmc-client`; 6) запись в STATUS (сверху журнала) и CODEMAP.
- Корень рендера: `T(pos)·R_y(180−body)·S(−1,−1,1)·S(scale)·squash·T(0,−1.501,0)·S(mscale)`. Если у рендерера есть `setupRotations` с трансляцией (кальмар: 0.5 до и −1.2 после поворота = 0.7 блока вниз) — зашить в смещение частей модели (`SQUID_DY = 11.2` px).
- Метаданные (`world/level.rs`): Mob#15 флаги → `mob_flags` (бит 4 = агрессия, у зомби/пиглина/разбойников — руки); #16 bool → `baby` (у гаста — заряд); #16 INT → `swell_dir` (крипер — swellDir, слайм/магмакуб — размер); #17 bool → `bool17` (creepy эндермена); Sheep#18 → `byte18`; Entity flags бит 8 = sprinting. Типы 13/14/15/19/21–32/34–38 парсятся пропуском — иначе разбор обрывается.

## Не рендерятся (~35–40)
- **Нужна keyframe-система** (`AnimationDefinition.bake/apply`, `applyWalk`): (bat, frog, tadpole — готовы, шаги 17–18), axolotl, allay, armadillo, sniffer, breeze, warden; плюс точная анимация верблюда (ходьба/сидение/рывок) и прыжка кролика.
- **Водные:** pufferfish, tropical_fish (нужен цвет/узор), nautilus.
- **Нижний мир/боссы/прочее:** ender_dragon, wither, shulker, паук-жокей и т. п.

## Упрощения в уже сделанных (VANILLA-UNSURE в коде)
- Нет детёнышей (baby-модели/текстуры) ни у кого.
- Варианты/окрасы не читаются: корова/свинья (temperate), кролик (brown), лиса (red), лошадь (brown, без маркировок), лама (brown/creamy), панда (обычная), волк/кот (базовые), житель (без профессии/биома/шляпы).
- Позы: нет сидения/сна/лёжа у лисы, кота, волка, панды; нет подкрадывания; нет вставания на дыбы (лошадь, медведь).
- Предметы/блоки в руках и на голове: нет (тыква снеговика, блок эндермена, предмет ведьмы, арбалет/лук/заклинание у разбойников, золото/арбалет пиглина).
- Слои: нет внешнего слоя drowned, мухоморов мооширума, трещин/цветка голема, сёдел/брони/сундуков.
- Кальмар: упрощённые щупальца по возрасту и без наклона по движению (`Squid#aiStep` не портирован); glow_squid не светится.
- Черепаха: «на суше» = `on_ground`, без `isInWater`, без яйца.
- Слайм: внешний слой translucent — зависит от blending в `ParticleDraw`, не проверен.

## Keyframe-система (заготовка, 2026-11-09)
- Движок: `crates/render/src/keyframe.rs` (`AnimationDefinition::apply(model, millis, scale)`, `apply_walk(model, pos, speed, speed_factor, scale_factor)`); анимация **аддитивна** к позе, перед ней нужен `Model::reset_pose`. Кости ищутся по имени, нет — пропуск.
- Данные: `crates/render/src/keyframes_data.rs` — **генерируется** `python3 tools/gen_keyframes.py` (не править руками). Статики в верхнем регистре: `BAT_FLYING`, `BAT_RESTING`, `FROG_WALK/JUMP/SWIM/TONGUE/CROAK/IDLE_WATER`, `CAMEL_WALK/SIT/SIT_POSE/STANDUP/DASH/IDLE`, `HOP`, `IDLE_HEAD_TILT`, `SNIFFER_*`, `WARDEN_*`, `ARMADILLO_*`, `IDLE/SHOOT/JUMP/INHALE/SLIDE/SLIDE_BACK` (breeze), `SWIMMING` (nautilus). Baby/CopperGolem/Creaking не генерируются (добавить в `FILES` генератора).
- Применение: `BAT_FLYING.apply(model, age_ticks*50.0, 1.0)` (AnimationState: время в мс от старта; для looping берётся остаток от длины).
- Модели под keyframe нужны с теми же именами/иерархией частей, что в Java (`BatModel.createBodyLayer` и т. п.). Bat: body, head(right_ear,left_ear), body→right_wing→right_wing_tip, left_wing→left_wing_tip, feet.
- Блокер по состоянию: метаданные позы/флагов (Bat resting, Frog/Camel/Armadillo поза) не читаются в `world/level.rs` (~588–700).
- Следующий порядок: bat → frog/tadpole → camel (walk) → rabbit hop → armadillo → axolotl/allay/sniffer/warden/breeze.
