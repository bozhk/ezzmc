## Форматы пакетов 26.3 (из reference)
Clientbound:
- `system_chat`: Component(NBT network: `nbt::read_network`) + bool overlay.
- `disguised_chat`: Component message + ChatType.Bound.
- `player_chat`: varint globalIndex, uuid sender, varint index, optional(bool+256 байт signature), SignedMessageBody.Packed {string(256) content, i64 timestamp-ms, i64 salt, LastSeen.Packed = varint n(≤20) × [varint id+1; если 0 → 256 байт]}, optional Component unsignedContent (bool+NBT), FilterMask {varint type: 0 pass, 1 fully filtered, 2 partial + bitset(long[])}, ChatType.Bound.
- ChatType.Bound: Holder<ChatType> (varint id+1 → индекс в registry `minecraft:chat_type` из Configuration (`cfg.registries`); 0 → inline: 2×ChatTypeDecoration), Component name, optional Component targetName.
- ChatTypeDecoration: string translation_key, list<varint param 0 sender/1 target/2 content>, Style (NBT). Декор: `Component.translatable(key, params).withStyle(style)`. Стандартные: chat→`chat.type.text`(sender,content); say_command→`chat.type.announcement`; msg in/out → `commands.message.display.incoming/outgoing` серый курсив; team→`chat.type.team.text/sent`(target,sender,content); emote→`chat.type.emote`.
- `delete_chat`: MessageSignature.Packed → заменить на «Message deleted» (по подписи; для unsigned не нужно).
Serverbound (имена в generated: `chat`, `chat_command`, `chat_command_signed`, `chat_session_update`, `chat_ack`):
- `chat`: string(256), i64 ms, i64 salt (любая), bool signature=false, LastSeen.Update {varint offset, 3 байта bitset(20), i8 checksum (0 = не проверять)}.
- `chat_command`: string (без `/`).
- `chat_command_signed`: string, i64 ms, i64 salt, ArgumentSignatures {varint n=0}, Update. Ваниль без ключей шлёт signed, если у команды есть signable-аргументы (say/msg/me…), иначе `chat_command`. Без дерева команд решить нельзя → пробовать `chat_command_signed` с пустыми подписями для всех; проверить вживую `/say hi`, `/time query daytime`. Ошибка/кик unsigned → переключить.
- offset в Update = число принятых player_chat с подписью с прошлого раза; для unsigned-сервера 0 (bitset нули, checksum 0).

## Ванильное поведение (ChatComponent/ChatScreen)
- Ширина `floor(opt*280+40)`, высота `floor(opt*160+20)` (focused/unfocused опции), `scale`=chatScale, строк на страницу = высота/line_height, line_height=`(int)(9*(spacing+1))`.
- Низ чата `floor((gh-40)/scale)`; entryHeight=`(int)(9*(spacing+1))`; textY = entryBottom − `round(8*(sp+1)−4*sp)`; смещение x +4; фон строки: fill(−4, top, maxWidth+8, bottom, black(alpha*bgOpacity)); bgOpacity=`textBackgroundOpacity` (0.5); textOpacity=`chatOpacity*0.9+0.1`.
- Затухание вне экрана: `t=1−(ticks−added)/200; t=clamp(t*10,0,1)²`; при открытом чате alpha=1; рисуются строки с alpha>1e-5.
- Метка-индикатор слева (`handleTag`): fill(−4,entryTop,−2,entryBottom, цвет тега с alpha). system()/not_secure = 0xD0D0D0 (13684944), error=0xFF5555. Серверные system_chat → `systemSinglePlayer` (цвет 0xD0D0D0); unsigned player_chat → not_secure; disguised → system. Тултипы: chat.tag.system / chat.tag.not_secure, макс. ширина 210.
- Скроллбар (если открыт чат и есть что листать): x=maxWidth+4, ширина 2; цвет 0x33333A (3355562), при новом сообщении при скролле 0xCC3333 (13382451); alpha 170/96; вторая полоса 0xCCCCCC.
- История 100 сообщений (trimmed lines ≤100 строк). Скролл: колесо ×7 (без Shift), PageUp/PageDown = ±(linesPerPage−1). Новое сообщение при scroll>0 сдвигает scroll на 1 и ставит newMessageSinceScroll.
- ChatScreen: поле x=4, y=gh−12, ширина gw−4, без рамки, max 256; фон `fill(2, gh−14, gw−2, gh−2, black(textBackgroundOpacity))`; ↑/↓ история (`historyPos`, `historyBuffer` сохраняет набранное при уходе с конца); Enter: `normalize = trim + normalizeSpace (пробелы/табы → один пробел)`, пусто → ничего; добавить в recent; `/…` → команда (без `/`), иначе chat; закрыть экран. Esc закрывает. key.command открывает с "/" . Mouse: ЛКМ по тексту — Click events (run_command → отправить как команду; suggest_command → вставить в поле; copy_to_clipboard; open_url по `chatLinks`/`chatLinksPrompt` — подтверждающий экран, можно пока открывать без него); Shift+клик — insertion.
- `chatColors=false` → вырезать §-форматирование/цвета из текста (ChatFormatting.stripFormatting).
- Overlay (action bar): `overlay=true` → `Gui#setOverlayMessage`, 60 тиков, над хотбаром gh−68 (уже есть `App.overlay`).
- Старые § коды в тексте компонента парсятся StringDecomposer (§0-f, k l m n o r) → применять в `draw` по тому же правилу; текущий `TextRenderer::draw` знает только a/c/r.
