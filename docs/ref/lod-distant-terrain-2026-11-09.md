# LOD дальнего рельефа и нагрев CPU на больших дальностях (идея, НЕ реализовано, не ваниль)

Статус: только заметка. LOD — не ванильное поведение; чтобы делать, нужна запись `DEC` в STATUS.md.

## Проблема
На дальности 127 мы мешим каждую секцию полностью (3D-меш, как в ванили): сотни тысяч секций →
~375% CPU на меш-потоках, CPU до 101°C; плюс кадры не ограничены (400+ fps, vsync выкл).

## Как это делает техника «LOD» (по описанию из документации)
- Две зоны: вблизи (напр. 24 чанка) обычные секции со светом/симуляцией; дальше (до 1024 чанков и больше) упрощённый рельеф.
- Мир делится на плитки до 22 уровней. С 6-го уровня (клетки от 64 блоков) плитка — карта высот поверхности и воды, без толщи под землёй. Дальше клетки ещё крупнее (~1/48 расстояния).
- Дальние плитки не попадают в World, освещение, симуляцию и граф пещер: отдельный слой геометрии.
- Отдельные потоки: «сэмплеры» (данные плиток; ~2/3 ядер при ≥8 ядрах, максимум 8) и свой пул меша; кэш плиток на диске.
- Цена: 1024 чанка LOD ≈ 2,8 млн квадов (на слабых картах держать меньше).
- Судя по доке, работает в локальных мирах (плитки считаются из генератора мира); как для удалённого сервера — не проверено.

## Дешёвые меры без LOD (ванильные, можно сделать сразу)
1. Лимитер кадров «Efficient»: спать последние ~0,5 мс вместо активного ожидания; сетка слотов.
2. «Battery mode»-подобный режим: ≤60 fps в мире, ≤30 в меню/без фокуса, половина потоков меша.
3. Ограничить потоки меша и скорость выдачи заданий (сейчас `MAX_PENDING = 128`).
4. FPS-лимит по умолчанию вместо «максимум».

## Уже сделано в этой сессии (2026-11-09), чтобы не потерять контекст
- Причина «дыр» на дальности 127 — переполнение арены вершин (20 млн): `VERTEX_CAPACITY` → 80 млн, `MAX_SECTIONS` → 65 536.
- `RebuildQueue`: пачка кандидатов раз в 16 вызовов + срочная очередь для правок блоков.
- `mesh_section`: быстрый выход для воздушных и закрытых сплошных секций.
- `ChunkBatchSize` (порт `ChunkBatchSizeCalculator`) вместо константы 9.0.
- F3: VRAM и мощность GPU через `nvidia-smi` (фоновый поток).
