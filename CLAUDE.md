# CLAUDE.md — читай ЭТО первым (60 секунд), потом действуй

**ezzmc** = клиент Minecraft Java на Rust, **приватный, оффлайн, без аккаунтов**. Две цели: (1) максимальная оптимизация, (2) вход на серверы любой версии 1.5.2 → latest с `online-mode=false`. **Всё поведение — ВАНИЛЬНОЕ** (читай оригинал в `reference/`, переводи на Rust).

## Источники для порта (по приоритету)
1. **Исходник Mojang** нужной версии: `reference/<ver>/` (получить: `cargo xtask fetch-reference <ver>`) — истина о ванили.
2. **Data Generator** `--reports` — пакеты/регистры/блоки/предметы (данные для кодогенерации).
3. **Соседние Rust-клиенты владельца, только чтение**: `~/pomme` (Pomme, ваниль 1.20→26.3, лучше всего для новых версий) · `~/horizon-1.20.1` и `~/horizon-launcher` (Horizon, протокол 763). Готовые решения брать можно; **НЕ помечай** в коде, комментариях, STATUS/CODEMAP/TASKS, что это взято из pomme/horizon (ни `// FROM:`, ни упоминаний; помечать можно что угодно другое: `VANILLA:`, `VANILLA-UNSURE:`, и т. п.). Это не истина о ванили: при сомнении сверяй с п.1. Не менять их файлы, не подключать как зависимость.
4. Записи трафика, wiki.vg/minecraft.wiki, ViaVersion и др. — для перекрёстной проверки и версий **старше 1.20** (там соседние клиенты не помогут).
5. Свои выжимки `docs/ref/*.md` — читай первыми, чтобы не перечитывать исходники.
**Нет эталона и нет готового решения у соседей** → `fetch-reference`, а не память.

## Цикл работы (делай, а не думай)
1. Выбери задачу (TASKS.md), пометь `[~]`, объяви класс S/M/L.
2. Открой эталон (`reference/<ver>/…`, выжимки `docs/ref/`). Нет эталона → `cargo xtask fetch-reference <ver>`.
3. Пиши код сразу. Порт с эталона, комментарий `// VANILLA: Класс#метод (версия)`.
4. Проверь: `cargo check -p <крейт>` → целевой тест → в конце fmt + clippy.
5. Обнови: `STATUS.md` (журнал, баги, TODO), `CODEMAP.md` (файлы), `TASKS.md` (`[x]`).
5а. **MCP для тестов:** новая игровая функция, которую можно проверить в живой игре (ввод, экран, действие, состояние) = расширь управление агентом: команда в `crates/client/src/control.rs` + инструмент в `tools/ezzmc_mcp.py` (+ поле в `state`, если нужно). Проверь функцию через MCP вживую; «готово» без этого — только с пометкой «не проверено вживую» в журнале.
6. Следующая задача. Не останавливайся для отчёта, пока не упёрся в потолок бюджета или блокер.

## Что решено ЗАРАНЕЕ (не обсуждай, не взвешивай, не предлагай альтернативы)
| Вопрос | Решение |
|---|---|
| Язык/ядро | Rust stable, workspace из крейтов (GOAL §6) |
| Окно / GPU | `winit` + `wgpu` |
| Математика | `glam` |
| Сеть | std-потоки + блокирующие сокеты + `crossbeam-channel` (без tokio) |
| Сжатие | `libdeflater` (zlib), `flate2` только как запасной |
| Параллелизм меша/ресурсов | `rayon` |
| Сущности | плоские SoA/арены, **без ECS** |
| JSON/NBT | `serde` + `serde_json`; NBT — собственный крейт-модуль |
| PNG / аудио / шрифты | `image` / `symphonia` + `cpal` / `ab_glyph` |
| Zip/jar | `zip` + `memmap2` |
| Ошибки / логи | `thiserror` / `tracing` |
| Тесты / бенчи | `cargo test` / `criterion` |
| Аккаунты | **нет**; offline-логин, unsigned-чат |
| Одиночная игра / встроенный сервер | **позже** (глава 22 в TASKS.md, после M1, главы 18 и вехи дракона); сейчас не брать |
| Графика / compute-рендер | Только ванильный путь. Compute (MDI/Hi-Z, `--compute-renderer`, F8) **заморожен** до конца проекта; не трогать, не чинить, не включать в запуск |
| Моды, Realms, Bedrock, бета/альфа | **нет** |
| Несовпадение версий клиент↔сервер | подключаемся молча на версии сервера (автодетект по ping), без предупреждений |
| Новая зависимость вне списка | можно, если нужна для задачи: добавь строку в `STATUS.md → Решения` и иди дальше |
| Стиль имён | Rust-идиомы; имена Mojang переводи в snake_case |
Изменить это может только человек (запись `DEC` в STATUS.md).

## Если сомневаешься — правила по умолчанию
- **Как в ванили?** → открой эталон. Эталона нет/не нашёл за 3 поиска → портируй ближайшее по смыслу, поставь `// VANILLA-UNSURE:` + строка в `STATUS.md → Баги [vanilla-diff]`, иди дальше.
- **Два рабочих способа** → выбери тот, что проще И ванильно-эквивалентен; без обсуждения.
- **Нет данных/сервера для проверки** → напиши код + тест на записанных/синтетических данных, пометь «не проверено на живом сервере» в журнале.
- **Задача слишком большая** → раздроби на подзадачи в TASKS.md (новые номера) и делай первую.
- **Ошибка не уходит** → 3 попытки, потом `Блокеры` и следующая задача.
- **Нашёл чужой баг/недоделку** → запись в `Баги`/`TODO`, не чини, если не в твоей задаче.
- **Хочется «улучшить»** → нельзя, если меняет поведение (ваниль). Рефакторинг без причины — нельзя.

## Сверка с ванилью бок о бок (стенд) — НЕ ЗАБЫВАТЬ
Скриншоты слева ezzmc / справа ваниль 26.3 синхронны **только** потому, что ванильная Java в режиме наблюдателя следит за Rust-клиентом: `Vanilla` в spectator, после **каждого** переподключения `EzzBot` выполнить `spectate EzzBot Vanilla`. Камера ванили идёт от глаз `EzzBot`. Если в ванили нет синхронизации — это не баг ezzmc: проверь `spectate`. **Стенд-сервер:** ванильный 26.3 в `reference/_server/26.3` (`online-mode=false`, порт **25611**; запуск `cargo xtask server 26.3 25611`), ezzmc: `ezzmc-client --connect 127.0.0.1:25611` под ником `EzzBot`. Консоль сервера — fifo в `scratchpad/in` (`echo "cmd" > fifo`), путь привязан к процессу сервера; если fifo нет — найти через `ls /tmp/claude-1000/*/*/scratchpad/in` или перезапустить сервер. Ваниль-клиент запускается `vlaunch.sh` (Java 25 из TLauncher, ник `Vanilla`, `--quickPlayMultiplayer 127.0.0.1:25611`). Сначала читай секцию «Стенд» в docs-файле, не спрашивай человека.
Подробности стенда (время 12700, clear, невидимость, `nocol`): `docs/ref/vanilla-compare-2026-11-08.md`.

## Живая проверка: СНАЧАЛА пересобери бинарник — НЕ ЗАБЫВАТЬ
MCP (`tools/ezzmc_mcp.py`, `game_launch`) запускает **`target/fast/ezzmc-client` (профиль `fast`: без LTO, инкрементальный)**, а `cargo check`/`cargo build` (debug) его **не обновляют**. Перед любой проверкой вживую: `cargo build --profile fast -p ezzmc-client`, затем `game_stop` + `game_launch` (запущенный процесс остаётся старым). Не уверен, свежий ли бинарник: `find crates -newer target/fast/ezzmc-client -name '*.rs'` — если что-то нашлось, он устарел. Результат «не работает» без этой проверки недействителен.
